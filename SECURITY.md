# Security policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately by email to **mukku.m13@gmail.com**. Include enough detail to reproduce the issue, the affected file or behavior, and any safe remediation suggestions.

Please do not include real applicant names, phone numbers, addresses, health details, credentials, tokens, or other sensitive personal data in a report. Use fictional examples or redact sensitive values.

This project is maintained on a best-effort basis. Do not publicly disclose a vulnerability until the maintainer has had a reasonable opportunity to review it.
