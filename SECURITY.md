# Security

## Reporting a vulnerability

Please report suspected security vulnerabilities privately by emailing **mukku.m13@gmail.com**. Do not include secrets, personal data, Aadhaar numbers, medical details, phone numbers, or other sensitive applicant information in a report.

Please provide enough detail to reproduce the issue safely, including the affected file or page, the observed impact, and any non-sensitive reproduction steps. Allow time for the issue to be reviewed before publicly disclosing it.

## Scope and limitations

This project is a static web guide and includes documentation and a zero-dependency Node regression suite. The live Telegram/n8n service described in project documentation is operated outside this repository. Reports about that service may still be sent to the address above, with only the minimum non-sensitive detail needed to identify the issue.

This document does not promise a response time, bounty, or guaranteed remediation.
