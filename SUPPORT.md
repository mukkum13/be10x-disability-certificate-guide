# Support

This repository provides process guidance and an offline reference web UI. It does not diagnose, determine eligibility, provide legal advice, approve applications, or replace a doctor, medical board, government office, or official UDID guidance.

For project bugs, unclear documentation, or contribution questions, open a GitHub issue using the appropriate template. For suspected vulnerabilities, use the private process in `SECURITY.md` instead of a public issue.

Do not submit real applicant names, phone numbers, addresses, health details, identity documents, credentials, tokens, or other sensitive data in issues, pull requests, screenshots, or emails. Use fictional examples and redact logs.
