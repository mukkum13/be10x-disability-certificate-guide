# Support

## What this project supports

This repository supports the static web guide and its documented local workflow. The web UI can be served with a static file server, and the repository includes a zero-dependency Node regression test for that UI.

The guide provides process information only. It does not diagnose, assess eligibility, give legal advice, approve applications, or replace an official authority, doctor, or medical board. Coverage is limited to information supported by reviewed sources in `docs/SOURCES.md`.

## What is outside repository support

The live Telegram bot and n8n workflow are operated outside this repository. Availability, delivery, hosting, external services, and district-specific decisions are not guaranteed by this codebase. For official application decisions or current local procedures, consult the relevant official authority and the official UDID portal.

## Getting help

For a reproducible project issue, open a GitHub issue with a short description, expected behavior, actual behavior, affected file or page, and safe reproduction steps. Use fictional data only.

For a suspected security vulnerability, follow `SECURITY.md` and email **mukku.m13@gmail.com** privately instead of opening a public issue.

Never include names, phone numbers, addresses, Aadhaar numbers, medical details, credentials, tokens, or other sensitive data in support requests.
