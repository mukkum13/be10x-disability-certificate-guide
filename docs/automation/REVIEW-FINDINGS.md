| 4 | Fail-safe branch's optional "translation-only call" could still let an LLM alter the fixed message | Codex #3 | CRITICAL | **Resolved.** Translation step removed from Node 6 in this revision; fail-safe ships in English only for this skeleton (multi-language fail-safe translation deferred to a future gate, tracked as an open item below, not silently solved with an LLM call). |
